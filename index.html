How it works

The docs only show what a script has run

A page can't be marked Reviewed on trust. The commands live in a script, the script runs end to end, and the page displays the exact text of the script.

1

Script

A bash script in Docs.Verify/Scripts runs every command from the page in a clean folder and checks the result: files, builds, ports, database rows, HTTP responses.

→
2

Snippet

Docs.SnippetGen cuts marked regions out of the scripts at build time and warns when a page was tested against an older release.

→
3

Page

The page renders the snippet, not hand-typed text, and carries a Reviewed chip with the release it was last verified against.

I traced both errors and sent a fix in ShiftTemplates #13. The team then fixed it upstream in their own way; on 2026.10.12.1 every combination builds, so I closed my PR and changed the docs and script to check that they keep building.

A tutorial that couldn't run as written

"Your first entity" told readers to generate a Vehicle, but the sample app already has one, so the command stops with "Creating this template will make changes to existing files". The old check script hid this by deleting the sample's files before running.

The tutorial now uses a new Warehouse entity, and the script proves the whole path: generate, add fields, migrate, sign in, create a warehouse through the API and see it in the list.
